# D · 智启新境

以统一的明亮天蓝色、自然留白和橙色强调建立独立的视觉方向，沿用思源黑体。与 A 的全幅工业背景、B 的产品画册和 C 的深色技术舞台区分，D 采用居中的品牌主张、全景互动展示台、错位双业务卡片、行业面板和开放式产业网络。

## 内容与交互

- 首屏：气缸套形态环绕巡展、活塞连杆曲轴剖面、机器人关节动画，可切换、暂停，响应减少动态偏好。
- 业务与行业：保留气缸套及机器人两大业务，汽车零部件、食品机械、家用电器、物流与仓储四个应用方向。
- 科技研发：技术创新、标准化建设、知识产权、质量管理、博士后工作站五个完整栏目。
- 企业概况：沿用原有三段完整介绍与园区照片；15 个集团成员、战略合作伙伴完整图册均可进入独立内容页。
- 新闻、投资者关系、英文资料、招聘和联系方式保留，产品图册继续逐件展示 23 件可辨识气缸套。
- AI 连接图属于未来制造愿景，说明材料、检测、系统集成与生产协同的联系，不宣称已有 AI 产品或运行中的 AI 系统。

## 维护

`build-d.cjs` 生成独立首页，`d.css`、`d.js` 管理版式与交互；共享内容页通过 `?theme=d` 和 `content-d.css` 显示 D 风格。四套首页的切换入口和方案总览已加入 D。

执行 `node design-proposals/build.cjs` 会生成 A、B、C、D 四套首页。执行 `npm run build` 检查站点并生成用于部署的 dist 目录。

验证覆盖桌面、平板、手机（320–1920px）、顶部导航与企业锚点、产品/机器人切换、产品详情、行业切换、咨询窗口、内页主题保持和完整模块数量。
