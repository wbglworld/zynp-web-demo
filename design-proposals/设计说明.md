# 中原内配官网改版：三个版式方向

## 第二版更新

三个首页现已接入独立站内内容和持续动效。当前交付范围、缺失素材与验证结果请先阅读 [内容迁移与动效说明](内容迁移与动效说明.md)。以下为第一版设计理念记录，其中详情弹窗已改为站内详情页面，旧官网入口已替换为本地栏目。

日期：2026年10月31日。用途：比较品牌风格、首页版式与交互方向。三个方案都是完整的首页概念原型，包含桌面和手机布局；还不是已上线网站或全站开发成品。

## 如何查看

双击本目录的 `index.html`，先看三个方案的对比，再进入 A、B、C。各页面左下角可以切换方案。页面所需图片、样式与脚本均在本目录，保留目录结构即可离线预览；官网资料、电话和邮件等链接按按钮实际用途打开。

本机预览服务启动方式：在本目录运行 `node serve.cjs`，访问 `http://127.0.0.1:8766/`。如果端口已占用，先检查是否是已启动的本提案服务。

## A｜智造远景

目标：建立集团级工业品牌的规模感与可信度。三套中最接近本次三一参考方向。

- 首屏：真实智能产线为全幅背景，叠加产品概念图；左侧品牌主张、下方两条业务切换。
- 结构：品牌场景 → 企业身份 → 双业务 → 行业标签页 → 技术特写 → 动态 → 咨询。
- 色彩：深蓝 `#081B2C`、品牌橙方向 `#EC7B36`、白色与浅灰。
- 互动：产品/机器人首屏切换，四行业内容切换，业务和技术详情弹窗。
- 适合：集团形象升级、国内外客户初次访问、两条业务并重。
- 落地需求：高质量真实产线视频、产品工程渲染、近期业务案例。首屏未来可改为低频率的视频循环，同时保留静态封面。

## B｜精密之美

目标：用专业画册的编排方式，把精密制造做得更有产品感和品质感。

- 首屏：大字号中文与英文衬线标题，右侧拱形产品画面；正文留白、产品先行。
- 结构：产品视觉 → 两个错位业务版块 → 行业折叠面板 → 微观工艺细节 → 动态与联系。
- 色彩：暖白 `#F7F7F2`、深青 `#254A50`、暖橙 `#E66B2C`、浅灰绿。
- 互动：业务详情、单项展开的行业面板、技术说明与联系入口。
- 适合：国际化产品品牌、研发采购受众、对产品工艺与审美质感要求更高的方向。
- 落地需求：精细产品摄影、材料微观照片、清晰的技术文案。对动画和视频依赖较小。

## C｜未来工场

目标：突出机器人、系统集成与智能制造，把技术能力变成可以探索的内容。

- 首屏：技术舞台，默认机器人；可切换气缸套，并点击三个能力热点查看解释。
- 结构：业务探索 → 材料/检测/集成/协同能力链 → 行业入口 → 真实制造现场 → 咨询与动态。
- 色彩：墨黑 `#090F12`、薄荷绿 `#A7F7CE`、低饱和灰绿；使用细线与网格建立工程感。
- 互动：产品/机器人切换、能力热点、四段制造能力路径、行业详情。
- 适合：将机器人解决方案作为新品牌认知重点，面向技术团队和制造升级客户。
- 落地需求：实际产品和机器人模型、工程确认的结构说明、系统架构与案例。当前交互是二维概念图切换，未声称实现真实三维模型或数字孪生。

## 三个方向的建议

建议优先推进 A：较容易兼顾集团实力与双业务客户路径。若希望品牌更克制、更具产品质感，可选择 B。若明确机器人是下一阶段的主要传播方向，可选择 C。融合时保留一个主结构，再吸收其他方案的局部表现，避免将三个风格直接拼接。

## 参考网站与实际采用的理念

已于2026年10月31日用浏览器检查以下网站，并保存参考截图于上级 `output/playwright/`：

1. [三一集团官网](https://www.sanygroup.com/)：全幅场景首屏、主导航与辅助导航分层、全球化/数智化/低碳化叙事、研发/产品/解决方案入口以及企业实力。A借鉴其宏观场景与分层表达，不复制其素材、代码或版式细节。
2. [KUKA中国](https://www.kuka.cn/zh-cn)：产品、行业、应用等不同任务入口，以及场景化的机器人与自动化内容。用于三套方案的行业路径与C的能力探索思路。
3. [DMG MORI中国](https://cn.dmgmori.com.cn/)：产品与自动化方案入口、产品视觉和服务联系路径。用于B的产品导向及各方案的咨询入口组织。

这些是对参考网站可见结构的设计观察，不代表网站方公开声明的设计原则。

## 内容与素材边界

- 基于前一阶段已经完成的《官网内容梳理与改版准备》。第一条业务暂用官网正式用语“气缸套”，未将所有气缸套描述为钢材产品。
- 第二条业务使用“机器人与智能制造”，保留系统集成、机床联网、在线检测、MES、DNC、AGV等真实官网线索。
- 食品机械、家用电器、物流与汽车零部件来自2021年官网报道；具体项目和当前交付范围仍需企业核验。历史效率数据没有包装成对新客户的通用承诺。
- 文案为概念稿重写；1958年、上市代码002448等来自官网。没有编造产品型号、技术精度、产能数字或实时监控状态。
- `assets/cylinder.svg` 与 `assets/robot.svg` 是为此次版式制作的原创概念示意，非企业实际型号、CAD或产品结构图。确定方向后需以真实工程素材替换。
- 页眉文字标识是版式用的临时排字，最终应按正式VI和品牌文件还原。参考网站的Logo、图片、视频没有移植到提案中。
- 所有咨询操作只支持打开联系方式、整理/复制咨询要点和打开用户邮件客户端；没有自动发送、后台提交或伪造“发送成功”。

- `qa-browser.js`：通过playwright-cli执行的浏览器检查脚本。
